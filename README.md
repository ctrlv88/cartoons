# 🔬 PUPPET 3 — Анализ и объединение версий

Инструменты для сравнения двух версий PUPPET 3 (v13 и v14) и объединения лучшей физики.

## 📁 Структура

```
├── scripts/
│   ├── analyze.js    # Анализ различий между версиями
│   ├── merge.js      # Объединение файлов (замена физики)
│   └── server.js     # Локальный сервер с API
├── src/
│   └── App.tsx       # React-интерфейс (визуализация)
├── public/           # Результаты работы скриптов
└── dist/             # Собранный фронтенд
```

## 🚀 Быстрый старт

### 1. Клонировать и установить

```bash
git clone https://github.com/ctrlv88/cartoons.git
cd cartoons
npm install
```

### 2. Запустить анализ

```bash
node scripts/analyze.js
```

Что делает:
- Скачивает `puppet3 (13).html` и `puppet3 (14).html` с GitHub
- Извлекает все `<script>` блоки
- Классифицирует каждый (Физика v2, Физика v3, ASM, Кости и т.д.)
- Сравнивает попарно, находит различия
- Сохраняет `public/results.json`, `public/puppet3_v13.html`, `public/puppet3_v14.html`

### 3. Посмотреть различия в физике

```bash
node scripts/merge.js --diff
```

Показывает:
- Какие физические функции различаются
- Первое отличие в каждой функции
- Что есть только в одной версии

### 4. Объединить (взять лучшую физику)

```bash
# Физика из v13, остальное из v14 (рекомендуется)
node scripts/merge.js --physics-from=v13

# Или наоборот
node scripts/merge.js --physics-from=v14

# Просто объединить (v14 как основа)
node scripts/merge.js
```

Результат: `public/puppet3_merged.html`

### 5. Запустить локальный сервер

```bash
npm run build
node scripts/server.js --open
```

Откроется `http://localhost:3000` с визуальным интерфейсом.

## 📡 API сервера

| Endpoint | Описание |
|----------|----------|
| `GET /api/files` | Список локальных файлов |
| `GET /api/results` | Результаты анализа (JSON) |
| `GET /api/analyze` | Запустить анализ |
| `GET /api/merge?physics-from=v13` | Объединить файлы |
| `GET /api/proxy?url=...` | Прокси запроса (обход CORS) |

## 🔍 Что сравнивается

### Физические модули:
- `drawJet` — рисование струи
- `drawLogs` — колбаски
- `drawGas` — газы
- `puddlesV3` — лужи v3
- `wallSplat` — пятна на стене
- `contactStain` — заляпывание при попадании
- `trailPud` — след луж
- `emitAt` — точка испускания
- `liftFx` — эффект взлёта
- `pfx` — параметры по умолчанию
- `nozzleV` — скорость сопла
- `jetParcels` — частицы струи
- `natLand` — естественное приземление
- `lockV` — фиксация лужи

### Константы:
- `LIQ` — параметры жидкостей
- `GAS` — параметры газов
- `POOP` — типы эффектов

## 🎯 Стратегия объединения

**v14** — полная версия (содержит всё из v13 + ASM модуль сборки из частей)

Если физика в v13 работает лучше:
```bash
node scripts/merge.js --physics-from=v13
```

Это заменит все физические функции из v13 в файл v14, сохранив ASM и другие новые модули.

## 🖥️ Веб-интерфейс

Без Node.js сервера — работает напрямую через GitHub:
- Загружает оба файла
- Показывает анализ в браузере
- Визуальное сравнение в iframe

С Node.js сервером — дополнительно:
- API для анализа и объединения
- Прокси GitHub (без CORS)
- Автоматическое обновление

## 📝 Опции merge.js

```bash
--base=v14              # Базовая версия (по умолчанию v14)
--physics-from=v13      # Взять физику из этой версии
--output=merged.html    # Имя выходного файла
--diff                  # Показать различия без объединения
```
